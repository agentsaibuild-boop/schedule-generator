# Типове проекти

## 1. Разпределителна мрежа (Тестоград-type)
- Много еднакви участъци (~199м)
- 10 стандартни дейности на участък
- Pipeline overlap 16 дни
- Fixed days по DN

## 2. Довеждащ водопровод (Горноград-type)
- Променливи участъци (74-354м)
- 7-9 дейности на участък
- Последователно (1 екип)
- Productivities-based

## 3. Единичен участък (Среднево-type)
- 1 непрекъснат участък
- FS последователни + FF за design
- Productivities-based

## 4. ИНЖЕНЕРИНГ
- Проектиране + Строителство + Авт. надзор
- 3 фази, 780-1000 дни

## 5. Mega-scale (Долноград-type)
- >20км, >1000 задачи
- Само анализ + extract productivities

## 6. Аварийно/специализирано безизкопно (OUT OF SCOPE)
- microtunneling, pipe bursting (няма верифицирана норма)
- Уникални дейности, <20 дни
- НЕ включва HDD/хоризонтален сондаж: той е СТАНДАРТЕН метод за уличен
  водопровод (потвърдено от еталонен човешки график, 2026-08-06) и има
  верифицирана норма 56 м/ден (урок #32)
